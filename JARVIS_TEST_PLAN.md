## Как проверять результаты в Supabase

После каждого теста проверяйте что данные сохранились:

```sql
-- Последние 5 записей
SELECT content_type, summary, tags, priority, 
       metadata->>'feasibility_score' as f_score,
       metadata->>'impact_score' as i_score,
       created_at
FROM jarvis_memory 
WHERE status = 'active'
ORDER BY created_at DESC 
LIMIT 5;

-- Статистика по типам
SELECT * FROM get_jarvis_stats();

-- Логи действий
SELECT agent_id, action, status, created_at
FROM jarvis_agent_logs
ORDER BY created_at DESC 
LIMIT 5;
```
