# firecrawl-tools

## Назначение
Веб-скрейпинг и AI-мониторинг сайтов (новости отрасли, тендеры, изменения в НТД, сайты конкурентов).

## Репозиторий
`github.com/kairat-jarvis/firecrawl-tools`

## MCP-серверы
- `firecrawl` — scrape, crawl, map, extract
- `supabase` — сохранение результатов мониторинга

## Когда использовать
Триггеры: «спарси сайт …», «что нового на …», «мониторь …», «вытащи данные с …», «проверь тендеры на …», «обнови базу НТД с сайта …».

## Интеграция с JARVIS
- **Пишет в**: `jarvis_memory` (type='monitor_result', tag='web')
- **Логирует в**: `jarvis_agent_logs` (action='web_scrape', url=<…>)
- Для повторяющегося мониторинга — обёртывать в n8n workflow (→ `tools/n8n-mcp`).

## Правила
- Разовый парсинг — напрямую через Firecrawl MCP.
- Регулярный — через n8n cron + Firecrawl.
- Уважать robots.txt и rate limits.
