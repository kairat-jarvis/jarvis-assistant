# n8n-mcp

## Назначение
MCP-сервер для управления n8n workflow'ами. Автономные cron-задачи (AI-мониторинг, дайджесты, парсинг), которые пушат результаты в Telegram или `jarvis_memory`.

## Репозиторий
`github.com/kairat-jarvis/n8n-mcp`

## MCP-серверы
- `n8n-mcp` (сам этот пакет)
- `supabase` — workflow'ы пишут в `jarvis_memory`
- Telegram Bot (только push) — нотификации пользователю

## Когда использовать
Триггеры: «запускай каждый …», «по расписанию …», «подписаться на …», «мониторить …», «дайджест раз в …», «автоматизируй это».

НЕ использовать для: интерфейса чата, синхронных задач (это делает Claude напрямую).

## Интеграция с JARVIS
- **Workflow'ы пишут в**: `jarvis_memory` (type='monitor_result')
- **Push**: Telegram Bot → пользователь
- **Экспортированные workflow'ы**: `n8n_workflows/*.json` (в корне репо)

## Правила
- n8n только для автономных cron-задач, НЕ для чата.
- Каждый новый workflow экспортировать в `n8n_workflows/`.
