# agsk3-workspace

## Назначение
Каталог АГСК-3 (Альбом готовых строительных конструкций) — 233 966 позиций. Поиск конструкций, узлов, типовых решений по параметрам.

## Репозиторий
`github.com/kairat-jarvis/agsk3-workspace`

## MCP-серверы
- `supabase` — таблица `agsk_catalog` (233,966)

## Когда использовать
Триггеры: «найди в АГСК …», «подбери конструкцию …», «узел для …», «типовое решение …», «аналог из АГСК», «код АГСК».

## Интеграция с JARVIS
- **Читает**: `agsk_catalog`
- **Пишет в**: `jarvis_memory` (type='note', tag='agsk') — избранные подборки
- **Логирует в**: `jarvis_agent_logs` (action='agsk_search')

## Правила
- Для инженерных задач СНАЧАЛА проверить АГСК (типовое решение), потом — собственное проектирование.
- При подборе возвращать: код АГСК, описание, ссылку на альбом.
