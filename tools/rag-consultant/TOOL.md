# rag-consultant

## Назначение
RAG-пайплайн для базы НТД (нормативно-технической документации). Семантический поиск по пунктам СП/ГОСТ/СНиП, генерация ответов с цитированием.

## Репозиторий
`github.com/kairat-jarvis/rag-consultant`

## MCP-серверы
- `supabase` — таблицы `ntd_documents` (395), `clause_vectors` (90,262), `documents` (166)
- `firecrawl` (опц.) — парсинг новых НТД с сайтов

## Когда использовать
Триггеры: «по СП …», «что говорит норматив», «требования к …», «пункт N.N.N», «сошлись на ГОСТ», «подскажи по нормам», «проверь по НТД».

## Интеграция с JARVIS
- **Читает**: `ntd_documents`, `clause_vectors`
- **Пишет в**: `jarvis_memory` (type='note', tag='ntd') — сохраняет найденные ссылки
- **Логирует в**: `jarvis_agent_logs` (action='rag_search')

## Правила
- СНАЧАЛА искать в базе НТД, и только если ничего не найдено — делать web-поиск.
- Всегда возвращать ссылку на пункт (номер, документ, год редакции).

## Статус
🟢 Production — база заполнена, RPC-функции работают.
