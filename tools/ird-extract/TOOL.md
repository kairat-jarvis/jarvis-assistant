# ird-extract

## Назначение
Экстрактор ИРД (исходно-разрешительной документации). Распознаёт и структурирует ТУ, ГПЗУ, справки, согласования из PDF/сканов.

## Репозиторий
`github.com/kairat-jarvis/ird-extract`

## MCP-серверы
- `supabase` — сохранение структурированных ИРД
- `google-drive` — исходники (PDF) из рабочей папки проекта

## Когда использовать
Триггеры: «разбери ТУ …», «вытащи из ГПЗУ …», «структурируй ИРД по проекту …», «какие согласования есть по …», «проверь комплектность ИРД».

## Интеграция с JARVIS
- **Пишет в**: `jarvis_memory` (type='ird', project_id=<…>)
- **Связь**: `jarvis_projects.id` — каждый ИРД привязан к проекту
- **Логирует в**: `jarvis_agent_logs` (action='ird_extract')

## Правила
- ИРД всегда привязывать к конкретному `jarvis_projects.id`.
- При неполной комплектности — формировать список недостающих документов.

## Статус
🟡 MVP — базовый экстрактор ТУ работает, ГПЗУ в разработке.
