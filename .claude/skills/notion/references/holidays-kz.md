# Kazakhstan public holidays — data for Notion formulas

For working-day formulas, only holidays that fall on a **weekday** matter (weekends are already excluded by the weekend-subtraction math). Holidays that fall on Saturday/Sunday with official transfer to the next working Monday count as that Monday.

## Generating the timestamps for a new year

When 2027 / 2028 dates become available, don't compute them by hand — use `scripts/compute_holiday_ms.py` in this skill. Usage:

```bash
python scripts/compute_holiday_ms.py 2027-01-01 2027-01-02 2027-01-07 ...
```

It prints `YYYY-MM-DD  →  <ms>` lines ready to paste into this file or into a formula-generator script.
